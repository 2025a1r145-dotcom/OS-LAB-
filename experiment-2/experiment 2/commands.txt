EXPERIMENT 02: EXECUTION OF BASIC BASH/SHELL COMMANDS IN UBUNTU LINUX

AIM

To learn and execute basic Bash/Shell commands in Ubuntu Linux for directory navigation, file and folder management, text-file operations, and process inspection.

REQUIREMENTS

1. Ubuntu Linux operating system
2. Bash Shell
3. Terminal application

COMMANDS AND THEIR PURPOSES

1. Present Working Directory
Command: pwd
Purpose: Displays the full path of the directory currently being used.

2. Change Directory
Command: cd Documents
Purpose: Changes the current directory to Documents if it exists in the current location.

3. Remove an Empty Directory
Command: rmdir emptydir
Purpose: Deletes an empty directory named emptydir.

4. Create a Directory
Command: mkdir OS_Practical
Purpose: Creates a new directory called OS_Practical.

5. List Files and Directories
Command: ls
Purpose: Displays the files and folders available in the current directory.

6. Create a File
Command: touch notes.txt
Purpose: Creates an empty file named notes.txt if it does not already exist.

7. Copy a File
Command: cp notes.txt backup.txt
Purpose: Creates a duplicate of notes.txt named backup.txt.

8. Move or Rename a File
Command: mv notes.txt new_notes.txt
Purpose: Renames notes.txt to new_notes.txt or moves a file to another location.

9. Delete a File
Command: rm backup.txt
Purpose: Removes the file named backup.txt. This command should be used carefully.

10. Display File Contents
Command: cat notes.txt
Purpose: Prints the contents of notes.txt in the terminal.

11. Display the Beginning of a File
Command: head notes.txt
Purpose: Shows the first ten lines of notes.txt by default.

12. Display the End of a File
Command: tail notes.txt
Purpose: Shows the last ten lines of notes.txt by default.

13. Clear the Terminal Screen
Command: clear
Purpose: Clears the visible terminal screen.

14. View Running Processes
Command: ps
Purpose: Displays information about processes associated with the current terminal session.

PROCEDURE

1. Open the Ubuntu Terminal.
2. Type and execute each command individually.
3. Observe the output produced by every command.
4. Practise creating directories and files, copying and renaming files, displaying file contents, and removing files or empty directories.
5. Capture screenshots of the terminal execution and save them for the practical record.

EXPECTED OUTPUT

The commands display the current directory, navigate between folders, create and remove directories, list files, perform file operations, display text, clear the terminal, and show process information.

RESULT

The specified Bash/Shell commands were studied and executed to understand basic file-system operations and process management in Ubuntu Linux.
